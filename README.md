# Catálogo Digital XIROM 📖✨

Bienvenido al repositorio oficial del **Catálogo Digital XIROM**.  
Este proyecto reúne nuestros productos en un formato moderno y accesible, con soporte web y PDF.

---

## 🚀 Características principales
- **[Catálogo en línea](ca://s?q=Ver_catalogo_en_linea)** con navegación interactiva.  
- **[Versión PDF](ca://s?q=Descargar_catalogo_PDF)** para impresión o consulta offline.  
- **[Diseño responsivo](ca://s?q=Que_es_diseno_responsivo)** compatible con dispositivos móviles y escritorio.  
- **[Logotipo XIROM](ca://s?q=Ver_logotipo_XIROM)** integrado en la interfaz.  

---

## 📂 Contenido del repositorio
- `index.html` → Página principal del catálogo.  
- `catlogo_xirom.pdf` → Versión descargable del catálogo.  
- `dflip.min.css` y `dflip.min.js` → Librerías para el visor interactivo.  
- `themify-icons.min.css` → Iconografía utilizada en la interfaz.  
- `logotipo.png` → Imagen oficial del logotipo XIROM.  
- `README.md` → Este documento de presentación.
